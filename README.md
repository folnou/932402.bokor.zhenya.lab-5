# Лабораторная работа №5

**Вариант:** Любитель кино и сериалов  
**Тема:** «Любитель кино и сериалов» (Список фильмов к просмотру)  
**Цветовая гамма:** Чёрно-золотая  

## Выполненные требования

**DOM-манипуляции:**
*   Реализован поиск элементов через `getElementById`, `querySelector` и `querySelectorAll` с обязательной проверкой на существование перед использованием.
*   Динамическое создание строк таблицы (`<tr>`) и ячеек (`<td>`) при добавлении нового фильма через форму.
*   Изменение текста, классов и атрибутов (`data-id`, `aria-pressed`) для управления статусом фильма («к просмотру» / «просмотрено»).
*   Удаление отдельных элементов и полная очистка списка через манипуляцию с `tbody`.

**Интерактивность и события:**
*   Переключение темы (светлая/тёмная) по кнопке с изменением CSS-классов и сохранением выбора.
*   Скрытие и показ блока с таблицей фильмов по клику на кнопку.
*   Скрытие/показ текстового блока в `<aside>` («Любимые жанры») при клике на заголовок.
*   Использование делегирования событий для обработки кликов по кнопкам внутри динамически создаваемых строк таблицы.

**Обработка ошибок:**
*   Проверка существования элементов перед добавлением обработчиков событий или изменением стилей.
*   Валидация пользовательского ввода: проверка названия на пустоту и года выпуска на диапазон (1888–2100).
*   Безопасное чтение и запись в `localStorage` с обработкой возможных исключений (например, при повреждении данных).

**Сохранение состояния (localStorage):**
*   Сохранение массива фильмов (название, год, статус) между перезагрузками страницы.
*   Сохранение выбранной темы оформления (светлая или тёмная).
*   Сохранение состояния видимости таблицы (скрыта или отображается).
*   Автоматическое восстановление всех данных при загрузке страницы.

## Запуск

Откройте файл `lab5.html` в любом современном браузере. Для проверки работы скриптов убедитесь, что в настройках браузера не отключен JavaScript. Данные будут автоматически сохраняться в локальном хранилище браузера.

## Проверка

HTML, CSS и JavaScript код проверен визуально и с помощью консоли разработчика (F12). 
*   Отсутствуют ошибки в консоли при стандартном использовании.
*   Корректно работает валидация формы и вывод сообщений об ошибках.
*   Данные успешно сохраняются в `localStorage` и восстанавливаются после обновления страницы.
*   Интерфейс адаптируется под светлую и тёмную тему без потери контрастности.
